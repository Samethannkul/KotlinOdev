# TicketSales Uygulaması
Bu uygulama, uçak bileti satın alma işlemlerini kolaylaştırmak için geliştirilmiştir.

## Özellikler
- Uçuş bilgileri görüntüleme
- Türkçe dil desteği
- Tablet uyumluluğu

## Kurulum
1. Projeyi klonlayın: `git clone https://github.com/kullanici-adiniz/TicketSalesApp.git`
2. Android Studio'da açın ve çalıştırın.
